# 🐱 小猫躲猫猫（3 岁版）

给 3 岁小朋友在手机上玩的躲猫猫网页小游戏。纯前端、单页、离线可玩。

## 怎么玩

直接用手机浏览器打开 `index.html` 即可（无需联网、无需安装）。
推荐「添加到主屏幕」，就能像 App 一样点开玩。

> 提示：iOS Safari 首次点按后才会允许播放声音，这是系统限制，任意点一下就正常了。

## 玩法流程

1. **首页** — 小朋友自己点大数字 `1 / 2 / 3 / 4`，决定这次要找几个
2. **目标展示** — 显示这一局要找哪几个小伙伴（记住它们的样子）
3. **数到 10** — 全屏大数字 1→10 逐个弹出，同时中文语音朗读
4. **找猫猫** — 场景里的小动物躲在灌木、树桩、石头、草丛后面，只露出一点点身体
   - **点一下露出来的身体** → 就抓到了！小动物会说话，小猫会开心跳一下
   - **点错地方** → 温和的「唔～」音效，小猫左右摇头，不扣分
5. **全部找到** → 撒花庆祝，可以「再玩一次」或「换个难度」

## 角色

五个角色都是 **AI 生成的扁平卡通形象**（黑色描边 + 纯色块，中国儿童动画风格），
以透明 PNG 存放：

| 角色 | 特点 |
|---|---|
| 🐱 小猫 | 主角，一直在场景里。抓到会跳，点错会摇头 |
| 🦆 小鸭子 | 黄色，扁宽橙嘴，呆毛 |
| 🐿️ 小松鼠 | 棕色，戴圆眼镜，超大蓬松尾巴 |
| 🐊 小鳄鱼 | 绿色，长满尖牙的大嘴 |
| 🐘 小象 | 灰蓝色，大耳朵，长鼻子 |

## 技术要点

- **零依赖**：所有音效是 WebAudio 实时合成，语音用浏览器原生 `speechSynthesis`
- **图片躲藏几何**：角色是一张透明 PNG，`characters.js` 里定义要露出的
  **裁切区域**（像素坐标的 `regions`），运行时按比例缩放 + `clipPath` 裁切，
  再把灌木/树桩画在角色之上 → 边缘自然接上障碍物轮廓
- **障碍物可计算**：每个障碍物由若干椭圆拼成，代码能算出它在任意 `x` 处的
  表面高度（`coverTopAt`）和任意 `y` 处的左右边界（`coverEdgeX`），
  所以「探头 / 露耳尖 / 伸尾巴 / 垂鼻子 / 横探长吻」都能精准定位
- **关卡生成带校验**：每局随机分配位置和露出方式，并自动检查
  ①露出部分是否在画面内 ②是否和小猫重叠 ③各个命中区是否互相干扰
  （1000 局自动化测试：0 错误、0 重叠、0 越界）
- **自适应**：SVG viewBox 宽高比始终等于屏幕宽高比，横竖屏都不变形、不留黑边
- **适龄设计**：命中区最小 76 世界单位（约小朋友一个指头）、点错不惩罚、
  无倒计时无失败、大按钮大图标

## 文件

```
index.html           页面结构
style.css            样式与动画
characters.js        五个角色的图片引用 + 裁切区域定义
game.js              游戏逻辑（场景、几何、流程、音频、语音）
img/*.png            角色图片（已去白底 → 透明）
img/src/*.png        生图原始文件（白底），供 tools/white2alpha.py 重新处理
tools/white2alpha.py 白底 JPG → 透明 PNG 脚本
refs/                画风参考图
```

## 重新处理图片

如果重新生成了角色图（原图是白底 JPG，放在 `img/src/`）：

```bash
python3 tools/white2alpha.py
```

会输出透明 PNG 到 `img/`，并自动裁掉四周留白。

## 调试

- `preview-crops.html` — 显示各裁切区域单独渲染效果
